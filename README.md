# 🚀 Pro Media Studio v1.0.0

A modern, fast, and user-friendly cross-platform desktop application designed for seamless media processing, powered by Electron, Express, and yt-dlp.

---

## ✨ Features

* **Cross-Platform:** Fully optimized and tested for both **Windows** and **macOS**.
* **Smart Media Management:** Efficient backend architecture to handle robust media downloads and conversions effortlessly.
* **Clean & Modern UI:** An intuitive, sleek interface built for smooth user experience.
* **Lightweight & Fast:** Optimized resource usage for high-speed performance.

---

## 📥 Download & Installation

You can download the latest installer directly from the [Releases](../../releases) page:

* **For Windows:** Download `Pro.Media.Studio.Setup.1.0.0.exe` and run the installer.
* **For macOS:** Download `Pro Media Studio-1.0.0-arm64.dmg`, open it, and drag the app into your Applications folder.

---

## 🛠️ Built With

* [Electron](https://www.electronjs.org/) - Cross-platform desktop app framework
* [Express.js](https://expressjs.com/) - Backend server architecture
* [yt-dlp](https://github.com/yt-dlp/yt-dlp) - Core media processing engine
